# Inky Bird documentation

You can [browse the artwork](https://henrysowell.com/birds) without installing
Inky. To keep your own collections, install the controller and open its browser
journal. A physical frame, observation sources, and generation are separate choices.

These guides describe `main`. If you run a tagged version, start with the
[release notes and instructions for that version](https://github.com/veteranbv/inky-bird/releases).

## Install or upgrade

- [Start with approved art](settings.md#start-with-approved-art) without a
  source account, display hardware, or generation.
- Install the controller with [Docker](docker.md) or the
  [native setup](installation.md). [Choose hardware](hardware.md) if you want
  a dedicated e-paper display.
- [Set up owner access](browser-access.md) on a trusted network. For an existing
  installation, read the [migration guide](migration-v1.md) before claiming or
  changing access to retained data.
